# Reclaim Protocol verification letters

Early-beta workflow tools for user-authorized evidence from online accounts, shareable verification requests, verified reference letters, and verification of received Reclaim PDFs.

MCP endpoint: https://letters.reclaimprotocol.org/mcp (Streamable HTTP; no product account or API key).

The account holder must review the request and sign in at the browser handoff. A request URL is not proof that verification completed. Keep task tokens private. Verification and PDF downloads are currently free in this beta; see the service for current terms.

Full instructions: https://letters.reclaimprotocol.org/agents

For integrating verification into product code, use the developer plugin in the root repository.
